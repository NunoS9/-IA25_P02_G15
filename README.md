## Descrição dos Notebooks

### Notebook 1 — Classificação  
Aplica métodos de **classificação supervisionada** para prever uma variável alvo no dataset FIFA.  
**Objetivo:** treinar e avaliar modelos de Machine Learning para realizar previsões com base nos atributos dos jogadores.


### Notebook 2 — Clustering  
Utiliza técnicas de **agrupamento não supervisionado** para formar grupos de jogadores com características semelhantes.  
**Objetivo:** descobrir perfis de jogadores e padrões naturais no dataset sem usar rótulos.


### Notebook 3 — Association Rules  
Aplica o algoritmo **Apriori** para extrair **regras de associação** entre características discretizadas dos jogadores.  
**Objetivo:** identificar padrões frequentes e relações entre atributos como idade, overall, potencial e pé preferido.
